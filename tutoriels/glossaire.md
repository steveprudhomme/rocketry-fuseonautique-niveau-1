# Les mots de l’atelier

| Mot | Explication simple |
| --- | --- |
| Apogée | Le point le plus haut du vol. |
| ATH | Des informations dessinées par-dessus le film. |
| Axe X / Y / Z | Trois directions pour dire où se trouve un objet; Z est vertical dans notre scène. |
| Cache | Des résultats de calcul gardés pour éviter de tout recalculer. |
| Caméra | Le point de vue qui fabrique l’image du film. |
| CG | Centre de gravité : le point d’équilibre associé aux masses. |
| Clé / image clé | Une valeur enregistrée à une image précise. |
| Commit | Un état du projet enregistré dans l’historique Git. |
| Compositeur | Un atelier qui mélange et transforme des images. |
| Densité d’un volume | Un réglage qui rend la fumée plus ou moins épaisse visuellement. |
| Dérive | Le déplacement horizontal entre le départ et le retour. |
| Empty | Un objet vide qui sert de poignée ou de repère. |
| FPS | Nombre d’images affichées en une seconde. |
| Géoréférencement | Associer le dessin à un lieu et à un système de coordonnées. |
| Image clé relative / shape key | Une autre forme du même ensemble de sommets. |
| Interpolation | Calculer ce qui se trouve entre deux valeurs connues. |
| Lacet | Rotation autour de l’axe vertical, comme une toupie. |
| Maillage | Des points reliés qui forment la peau d’un objet 3D. |
| Masque | Une image ou une valeur qui dit où appliquer un effet. |
| Matériau | Les réglages de couleur, rugosité, transparence ou volume d’un objet. |
| Nœud | Une boîte de calcul reliée à d’autres par des fils. |
| Normalisation sonore | Ajustement du niveau d’un son vers une cible mesurée. |
| Orthophoto | Une photographie aérienne corrigée pour être utilisée comme une carte. |
| Parent | Un objet qui entraîne ses enfants quand il se déplace. |
| PBR | Une manière de décrire l’interaction d’un matériau avec la lumière. |
| Poussée | L’action du moteur qui accélère la fusée. |
| Rendu | Le calcul qui transforme la scène en image. |
| Scène | Un plateau de cinéma numérique. |
| Script | Une recette écrite que l’ordinateur exécute. |
| Séquenceur | L’endroit où l’on place les bandes d’images et de sons dans le temps. |
| Simulation | Un calcul avec des hypothèses, pas une mesure de la vraie fusée. |
| Soft Body | Un calcul de forme souple avec des points et des ressorts. |
| SRTM | Le jeu de données radar utilisé pour les grandes formes du relief. |
| Texture | Une image ou un calcul qui ajoute des couleurs ou des détails à une surface. |
| Traînée | L’action de l’air qui s’oppose au mouvement relatif dans l’air. |
| UV | Des coordonnées qui disent comment poser une image sur un objet. |
| Vecteur | Une flèche qui donne une direction; sa longueur n’a un sens physique que si une échelle est définie. |

Ces définitions servent aux exercices du projet; elles ne remplacent pas une définition réglementaire ou une notice de fabrication.
